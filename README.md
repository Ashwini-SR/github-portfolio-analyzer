# GitHub Portfolio Analyzer & Enhancer

## Problem Statement
Many students and early-career developers have GitHub profiles, but most are incomplete or poorly structured. Recruiters struggle to evaluate technical skills due to:
- Incomplete README files
- Low activity or inconsistent commits
- Poorly organized repositories
- No clear demonstration of impact

## Solution
This tool analyzes a GitHub profile and generates:
- A structured **100-point GitHub Portfolio Score**
- **Recruiter-focused breakdown** (Documentation, Activity, Technical Depth, Repository Strength, Impact)
- **Red flags** that might reduce hiring chances
- **Actionable improvement suggestions**
- **Hireability Indicator** (Low / Medium / High)

## Features
- GitHub API integration
- Real-time scoring
- Documentation and activity analysis
- Technical depth & impact scoring
- Recruiter red flag detection
- Clean, user-friendly interface
- Mobile responsive
- Instant actionable suggestions

## Scoring Dimensions
| Metric | Max Points |
|--------|------------|
| Documentation Quality | 20 |
| Activity Consistency | 20 |
| Technical Depth | 20 |
| Repository Strength | 20 |
| Project Impact | 20 |
